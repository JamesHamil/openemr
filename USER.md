# AgentForge User Document

The source of truth for the MVP target user, workflow, and use cases is [`USERS.md`](USERS.md).

This file exists because the AgentForge PDF uses both `USERS.md` and `USER.md` in different sections. To avoid submission ambiguity, both files are included.

Summary: the MVP focuses on a hospitalist preparing for inpatient rounds. The agent plan supports source-backed chart briefs, patient-scoped follow-up questions, missing/conflicting data warnings, and safe refusal of treatment directives. The MVP does not implement a working AI agent.
